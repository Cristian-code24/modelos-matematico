# NVIDIA AI Growth Modeler 🚀

Plataforma educativa e interactiva diseñada para la asignatura de **Cálculo Multivariado**. 
Este proyecto simula y explica de forma matemática y visual cómo influyen múltiples variables de inversión (I+D y Data Center) en los ingresos totales de NVIDIA usando el concepto de **Funciones de Varias Variables: $z = f(x_1, x_2)$**.

## ✨ Características Principales (Masterclass)
- **IA Narradora Dinámica:** Una IA integrada que analiza los valores en tiempo real y explica paso a paso el comportamiento matemático geométrico y monetario de la función.
- **Gráficas 3D/2D Interactivos:** Modelado en plotly al estilo GeoGebra para interactuar con planos cartesianos.
- **Animaciones Automáticas:** Botón integrado que simula los escenarios proyectando cambios fluidos en la gráfica.
- **Gráfico de Crecimiento:** Análisis de ganancias con barras interactivas.

## 🛠 Instalación y Uso Local

Este proyecto está construido con **Python 3** y **Streamlit**.

```bash
# 1. Clona el repositorio
git clone https://github.com/Cristian-code24/modelos-matematico.git

# 2. Instala los requerimientos
pip install -r requirements.txt

# 3. Ejecuta la plataforma
python -m streamlit run app.py
```
